# Steam账号状态自动化检测工具 使用说明

## 🚀 快速开始
1. **运行程序**
   双击 `DeltaSteamVerifier.exe` 启动工具

2. **配置 Steam 路径**
   点击右下角 `⚙ 设置` → Steam 选项卡 → 点击 `自动检测` 按钮自动填入 Steam 安装路径，也可手动输入

3. **导入账号**
   支持两种方式：
   - 点击 `导入 Excel` 按钮，选择包含账号密码的 `.xlsx` 文件（第一列账号，第二列密码）
   - 点击 `手动添加` 逐个输入账号密码

4. **开始检测**
   点击 `▶ 开始运行`，程序自动完成：
   ✅ Steam客户端启动 → ✅ 账号登录 → ✅ 游戏启动 → ✅ 封禁状态检测 → ✅ 结果记录

5. **查看结果**
   检测结果实时显示在右侧日志区，同时保存至 `result.log` 文件

## 🖥️ 界面说明

### 主界面
- 左侧：账号列表（支持导入/添加/删除）
- 右侧：运行日志实时输出
- 底部：开始运行、停止、清空日志、设置按钮

### 设置对话框（⚙ 设置）
通过 4 个选项卡管理所有配置，保存后立即生效无需重启：

| 选项卡 | 配置内容 |
|--------|----------|
| Steam | Steam 路径（支持自动检测）、游戏 App ID、进程名、子进程列表 |
| 路径 | 封禁截图目录、调试截图目录、按钮图片目录 |
| 时间 | 登录等待、进程超时/间隔、协议搜索、置信度、各类随机延迟范围 |
| 按钮 | 按钮图片文件名、开始游戏/协议按钮的超时/重试/延迟、协议可选开关 |

## 📌 核心功能
- **OCR智能识别** — 精准定位Steam客户端封禁提示弹窗（不支持多语言界面）
- **全自动流程** — 账号登录、游戏启动、状态检测、结果保存一键完成
- **图形化界面** — 账号管理、参数配置、日志查看全部可视化操作
- **Excel批量导入** — 支持从 Excel 文件批量导入账号
- **Steam路径自动检测** — 通过注册表和常见目录自动定位 Steam 安装位置
- **本地数据存储** — 检测结果自动保存至 `result.log`

## ⚠️ 重要注意事项
1. **屏幕锁定要求**
   - 检测过程中请勿操作鼠标/键盘
   - 避免其他窗口覆盖Steam客户端界面
   - 建议设置显示器常亮（防止休眠）

2. **运行环境要求**
   - Windows 10/11 系统
   - 屏幕分辨率 ≥ 2560x1440

3. **异常处理**
   如遇程序无响应：
   - 点击 `■ 停止` 按钮尝试终止任务
   - 若无效，按 `Ctrl+Alt+Delete` 打开任务管理器
   - 结束 `DeltaSteamVerifier.exe` 和 `steam.exe` 进程
   - 重新运行程序
